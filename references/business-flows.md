# 智慧教学云 核心业务流程（实测走通）

> 2026-09-29 用 test.fuulea.com 实测。步骤中的选择器/类名已在站点验证过。

## 流程 A：布置作业（最核心闭环）✅ 实测走通

1. **进题库选题**
   - 直连 `/tk`，或从 `/task` 点新建任务面板里的「题库选题」
   - 题库 URL 形如：`/tk?category=1&tabIndex=0&nodes=-70643&questionTypeIndex=0&page=1`
2. **筛题**：知识图谱树 / 来源 / 题型 / 难度 / 地区 / 年级 / 年份 / 关键词，或用 **AI 搜题**
3. **加入选题**：题目卡片右下角「加入选题」按钮
   ```js
   agent-browser eval "(()=>{const s=[...document.querySelectorAll('span')].find(x=>x.textContent.trim()==='加入选题'&&x.offsetParent); s&&s.closest('button')&&s.closest('button').click(); return 'ok'})()"
   ```
4. **开题目篮**：点右下角 `.fixed-basket`（角标显示已选题数）
   - 篮内统计：`单选题1道共1道题 满分3分；`
   - 篮内按钮：**发布任务 / 加入课程 / 更多**
   - 单题操作：视频 · 收藏 · 相似题 · 移除选题 · 改编 · 设为不定项 · 排序后重排题号 · 记录 · 清空
5. **发布任务** → 跳 `/exercise/publish/task`，三步向导：
   - **① 发布设置**：任务名称、发布时间（默认「立即发布」）、截止时间
     - 基础设置：作业 / 教师批阅 / 允许晚交
     - 错题重练：个性错题 / 高频错题 / 不重练（选重练方式后系统自动向学生发布需重练习题）
     - 提交方式：逐题拍照 / 分组拍照 / 纸质卡
     - 补充信息：任务说明
     - 更多设置：作答全部题目 / 不限时作答 / 关闭学生讲题
     - 按钮：取消发布 · 下一步
   - **② 选择学生**：选择班级（管理的班级 / 靶向班）、选择学生、「已选: N 个班级」
     - 按钮：上一步 · 取消发布 · **发布任务**
   - **③ 发布成功**
6. 发布后回 `/task` 列表，按 Tab（已发布/未发布/已截止）与筛选定位。

> ⚠️ 第 5 步第 ③ 步会真实产生数据给用户班级，**执行前必须确认**。

## 流程 B0：创建课程 ⚠️ 有陷阱（实测）

`/course/new` 是 3 步向导：① 课程信息 → ② 课程目录 → ③ 章节内容

**第 1 步必填项与控件**

| 字段 | 必填 | 控件 / 取值 |
|---|---|---|
| 名称 | ✅ | input，**2–32 字符**（超界报「请输入课程名称,长度限制2-32个字符」） |
| 年级 | ✅ | `.grade-btn` 三选一：高一 / 高二 / 高三 |
| 级部 | ❌ | 下拉「请选择」 |
| 标签 | ✅ | 「请输入标签内容」+ **点「添加标签」按钮**才生效；不填报「请设置课程标签」 |
| 简介 | ✅ | textarea，上限 150 字；不填报「请填写课程简介」 |
| 可见范围 | — | `.range-btn` 三选一：仅自己 / 学校老师 / 全部学校用户 |
| 课程封面 | ❌ | 「上传封面」/「自定义封面」+ 选择文件（支持裁剪） |

**⚠️ 最大的坑：第 1 步点「下一步」就直接落库创建课程，没有最终确认页。**
所以填表前必须先把字段值全部确认好；一旦点了「下一步」，课程已存在，
中途放弃不会回滚，只能在 `/course/:id/edit` 删掉。

**第 2 步 课程目录**：系统**自动创建「第一章」和「1.1节」**（无需手动加）；
可改名、可「添加章节 / 添加子章节」，也可「上传电子版」（识别目录）。
跳到第 2 步时 URL 变为 `/course/<新id>/chapter/new`，**新 id 从这里拿**。

**第 3 步 章节内容**：给小节挂模块内容。

**删除课程**：`/course/:id/edit` 右上角「删除课程」按钮
→ 弹的是 **popconfirm 气泡**（`.ant-popover`，文案「确定要删除该课程吗？ 取消 确定」），
不是 `.ant-modal`；点气泡里的「确定」才真正删除，成功后跳回 `/course`。
注意：`/course/manage` 列表行内**没有**删除入口，只有 课程详情/关联分校/复制课程。

**核对创建结果**：`/course/manage` 列表行显示
`课程名称 | 学校 | 学科 | 年级 | 创建人 | 创建时间 | 关联分校 | 操作`；
学科由账号/站点决定（本测试账号固定为「历史」），创建时不可选。

## 流程 B：课程内建练习（教师备课）

`/course` → 选课程 → 章节 → `exercise/new` → `chooseQuestion`（逐题选）/ `choosePaper`（选整卷，可进 `:paperId` 预览）/ `addQuestion`（自建题）→ 保存发布。
章节下还可看 `analysis`（章节学情，得分率/完成率/平均分）与 `score`（成绩详情，按学生）。

## 流程 C：阅卷

- **作业**：`/task` → 快捷入口「批改阅卷」，或直接 `/task/correct-paper`。选择题自动判分，非选择题走自阅/互阅/师阅 + 复核。
- **考试**：`/exam` → 考试卡片「阅卷」→ `/exam/:id/marking/:examSubjectId`（多科目考试需先选科目）
  - 相关：`阅问题卷`、`submit/progress`（提交进度）、`offline/distribute/:examSubjectId/teachers`（线下分发）、`template-answer-sheet/scan`（扫卡）
- **移动端**：`/mark` 系列（`draw-guide` 画框引导、`slice` 切题、`mobile`）

## 流程 D：考试全流程

创建考试 `/exam/create`（选班级+学科+类型）→ 制答题卡（`answer-card` / `templates` / `mine`）→ 学生作答（纸卡走「扫卡」）→ 分发阅卷 → `/exam/:id/marking/:examSubjectId` 阅卷 → `submit/progress` 看进度 → 结束阅卷 → **公布成绩**（`/exam/:examId/analysis`，可撤销）→ 成绩分析：对比 / 成绩表 / 查看报告 / 划线 `division` / 学生考点分析 `student/nodeAnalysis/:examId/:userId` → `multiple-analysis` 多考联析

> ⚠️ 「成绩分析」在列表点下去是**开弹层**（`.ant-modal`）而非跳路由，注意检查 `.cdk-overlay-container`。

### D1. 给某场考试的某学科「关联已有试卷」✅ 实测走通（生产站）

> **批量做这件事（多学科 × 多场次）请看 `references/bind-papers-workflow.md`**，
> 那里是完整 SOP + 一条命令跑完的流水线；本节只讲单次操作与页面细节。

**场景**：考试的学科列表里，某个学科显示「制作答题卡 或 关联已有试卷」= 该学科尚未挂卷，
需要把已在课程里建好的试卷挂上去（例如生物卷）。

**入口**：`/exam/<考试ID>/detail` → 学科列表区

每行结构（`.ant-col-12` 内）：
```
【生物】  2026-09-28  修改
  制作答题卡 或 关联已有试卷 --- 发布 --- 阅卷分配 --- 开始阅卷
  交卷情况 --   阅卷进度 --   公布成绩  更多
```
- **未绑**：显示 `制作答题卡 或 关联已有试卷`（两个 `button.ant-btn-link`）
- **已绑**：显示 `考试内容：81402404 删除 --- 发布 --- 阅卷分配 --- 开始阅卷`

**操作步骤**

1. 打开 `/exam/<考试ID>/detail`
2. 定位目标学科行：
   ```js
   agent-browser eval "(()=>{
     const lbl=[...document.querySelectorAll('*')].find(e=>e.children.length===0&&e.textContent.trim()==='【生物】'&&e.offsetParent);
     let row=lbl; for(let i=0;i<6&&row;i++){ if(row.querySelector&&row.querySelector('button')&&row.innerText.includes('关联已有试卷')) break; row=row.parentElement; }
     const b=[...row.querySelectorAll('button')].find(x=>x.innerText.trim()==='关联已有试卷');
     b.click(); return 'clicked';
   })()"
   ```
3. 弹层「关联已有试卷」→「试卷编号」选择框，**输入试卷数字编号**
4. ⚠️ **必须按一次 Enter** 才会拉出候选项（只填值不触发搜索，实测不出现下拉）
5. 点候选项（显示的是试卷名称，需与考试名核对一致）
6. 点「确定」
7. ⚠️ **必须重新加载页面才能看到结果**（原地 `loadData()` 后 DOM 不更新，
   会误判成"没成功"）。用 `agent-browser open <同一个URL>` 重新打开，
   确认该行变成 `考试内容：<编号>`。

**实现细节**（从 `console` 抓到的源码，便于排查）：
```js
associatedPaper(e){
  this.modalSrv.create({
    nzTitle:"关联已有试卷", nzContent:ps, nzData:{examSubject:e},
    nzOnOk:n=>{ if(n.formValid(), n.formInvalid) return false; n.submit(); this.loadData(); }
  })
}
```
⇒ 点「确定」先做表单校验，校验不过会静默不提交（弹层仍关闭），
所以**"弹层关了"不等于"绑定成功"**，一定要回到列表核对。

**试卷编号从哪来**：各学科教研在课程里按考试建了章节。
- 每个学科有一门汇总课程：**`2024级<学科>考试汇总`**（英语特殊，有多门：
  `2024级英语考试汇总`/`2025级英语考试汇总`/`2026级考试汇总`，要挑 `2024级` 那门）。
- 课程里**一个章节 = 一场考试**，章节内容里试卷模块的 `#编号 满分N分 M道题`
  就是该场考试的该科试卷编号。
- 找法（技能已固化为可复用流程，见 `references/automation-playbook.md` 第 10 节）：
  `/course?schoolSubject=<学科ID>` → 打开 `2024级<学科>考试汇总` →
  进入任一章节 → 用 `nz-tree` 左侧目录逐章点击 → 读 `#(\d{6,})`。

⚠️ **各学科的章节命名风格不统一**，因此**不能只靠「章节名 = 考试名」来配对**：

| 学科 | 章节命名风格 | 备注 |
|---|---|---|
| 生物 / 语文 | 直接用考试名（`2024-2025第一学期高一第1次月考`） | 最规整，可逐字比对 |
| 化学 / 地理 | 简写 + 卷名（`24-25上·高一月考1_…`） | 学期(`上/下`)+年级+考试类型 |
| 数学 | 真实卷名（`龙岩市2024~2025学年第一学期期末高一教学质量检测`） | 覆盖场次少 |
| 物理 | 混合（`2024-2025第一学期高一第1次月考` / `24-25学年第二学期高一第1次月考试卷`） | 覆盖场次少 |
| 历史 | 简写（`24-25上·高一期中_高一历史`） | 覆盖极少 |

⇒ 对每一章都要**人工确认它对应哪一场考试**（看年级 + 学年学期 + 考试类型），
再用「弹层候选项的卷名」二次核对。

**「关联已有试卷」弹层的搜索行为（实测）**：
- 选择框支持按**试卷编号**或**试卷名称**搜索，输入后**必须按一次 Enter**。
- ⚠️ 按名称搜是**全库模糊搜索**，会返回**其它学校**的卷子
  （实测搜「第一次月考」返回过「2026-2027学年横岗高级中学高二第一次月考 - 历史」）。
  **绝不能只看名字像就点**——必须核对到能区分学校的特征（年级/届别/学年学期/龙岩一中字样）。
- 因此**优先用编号精确绑定**（编号唯一），名字只用来做二次确认。

**章节为空时**：页面显示「催录题目 —— 本章题目尚未录入，老师如需使用，可催录题目」，
说明该场考试的该科试卷还没录入，**无法关联**，需要先催录入。


## 流程 E：错题 → 重练 → 靶向（学情驱动闭环）

任务/考试数据 → 错题自动归集 → `/booklet`
1. 错题本筛选：个性错题 / 共性错题；按得分率区间、题型、知识点；题目聚合去重
2. 「导出错题」或「发布任务」（日错题本任务 / 重练）；题量过大时会提示「可以缩小筛选范围减少题量，是否继续发布」
3. 重练统计看：重练得分率、错题任务完成率、已重练/全部错题、日均重练
4. 需要针对性补强 → `/target`：
   - 对人靶向 `for-student`：按学生建靶向班（未选学生会提示「没有选择学生，不能创建靶向班」）
   - 对点靶向 `for-knowledge`：按知识点，看得分率/AI分层/优劣势，视角可切 知识图谱 / 趋势列表 / 对标高考
5. 学情验证：`/analysis`（年级/学科/班级/学生四层）+ 知识点图谱（气泡=信度：题量越多、时间越近信度越高）

## 流程 F：单词任务（英语）

`/vocabulary` → 选教材版本/册/Unit → 列表（英文·音标·汉语解释·高频错词·掌握人数·听写次数）→ 「加入选题」→ 单词篮 → 发布单词任务（考查方式：英译汉/汉译英/听写；英译汉学生填任一汉语释义即可）

## 流程 G：教辅录入（内容生产）

`/input/create` 建教辅（上传电子档；使用率低会提示「教辅使用率较低，暂缓录入」）→ 教辅分配 `/input/workbook` → 录入工单 `/input/input-self/<id>`（接收工单·开始录入·截图录入·文字录入·放弃录入·复制链接）→ 转码 → 统计：`input-statis/<id>`（个人）/ `input-team`（团队）/ `input-school`（区校）

## 流程 H：问卷调查

`/student-survey/home` → 新增问卷（填**金数据**问卷地址，验证通过后自动填问卷名称/描述/题目数）→ 选班级 → 选学生 → 发布；列表可 启用/暂停/查看数据/移除

## 流程 I：AI 技能控制台

`/algo/skill` → 新建技能（名称 + 定义技能）→ 编译（草稿/未编译/编译中/编译通过/编译失败）→ 开始测试（`algo-test/:algoId`）→ 发布（可撤回回草稿）
`/algo` 对话工作台可传附件（图片/PDF/Word，单文件有大小上限），右侧面板给「网页预览」「相关题目」。

## 流程 J：AI 搜题

`/search` 或题库页「AI 搜题」→ 输入自然语言（如「求二次函数对称轴」）→ 四阶段提示：正在理解你的描述 → 正在匹配相关知识点 → 正在筛选合适的题目 → 正在整理结果，马上就好 → 结果可加选题篮。

## 数据口径提醒

- 学情图表：**「所有成绩均由得分率折算成分数而来」**
